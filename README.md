# CloudMaker
GO скрипт, который управляет виртуальными машинами в контейнере. Удобный веб-интерфейс в localhost:8080. Информация о доступных ресурсах localhost:3000.
Реализованные пункты домашнего задания: 1, 2, 4, 6, 7, 8, 9, 10, 11, 12.

Тестовый cloud-init можно использовать для проверки соответствующего пункта.

для очистки всего мусора от скрипта можно использовать скрипт cleanup.sh.
